GIT HANDS-ON LAB 3 - SOLUTION
Branching and Merging
====================================================================

BRANCHING
---------
1. Create a new branch "GitNewBranch":
   $ git branch GitNewBranch

2. List all local and remote branches (the "*" marks the current
   branch):
   $ git branch -a

3. Switch to the new branch and add a file with content:
   $ git checkout GitNewBranch
   $ echo "This is a change made in GitNewBranch" >> branchFile.txt

4. Commit the changes to the branch:
   $ git add branchFile.txt
   $ git commit -m "Added branchFile.txt in GitNewBranch"

5. Check status:
   $ git status


MERGING
-------
1. Switch back to master:
   $ git checkout master

2. List command-line differences between master and the branch:
   $ git diff master GitNewBranch

3. View visual differences using the P4Merge tool:
   $ git difftool -t p4merge master GitNewBranch

4. Merge the branch into master:
   $ git merge GitNewBranch

5. Observe the commit graph after merging:
   $ git log --oneline --graph --decorate

6. Delete the branch now that it's merged, and check status:
   $ git branch -d GitNewBranch
   $ git status
